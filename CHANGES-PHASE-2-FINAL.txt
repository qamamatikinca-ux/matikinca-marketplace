LOADLINK WEBSITE — PHASE 2 FINAL CHANGE MANIFEST
Source used: matikinca-marketplace-main 12.zip

VISIBLE WEBSITE CHANGES
1. Functional burger menu
   - Added a real slide-out LoadLink menu instead of an inactive icon.
   - Includes Home, Jobs, Trucks, Contracts, Drivers, Messages, My Posts,
     Profile Settings, Driver Profile, Dealership Centre, Packages and Help.
   - Includes sign-in/sign-out state.

2. Professional profile settings
   - Added /account/settings.
   - Users can manage name, title, company, contact information, location,
     biography, profile picture, notification preferences and password.
   - Signed-in profile button now opens settings instead of returning to login.

3. Driver profiles
   - Driver hero section is positioned before the homepage footer.
   - Uses the truck-driver hero image already supplied in the project.
   - Added full /drivers page with seven approved profiles per page.
   - Driver submission requests only critical documents: ID/passport and
     driver's licence, plus PrDP only where applicable.
   - Police clearance and unnecessary documents are explicitly excluded.

4. Messaging
   - Added voice-note recording and playback support.
   - Added block and unblock controls per conversation.
   - Blocking prevents either side from sending until unblocked.
   - Existing 50-message daily standard limit remains enforced.
   - Messaging header now includes the functional LoadLink menu.

5. Seven-post pagination
   - Jobs/results: seven per page.
   - My Posts: seven per page.
   - Public dealership inventory: seven per page.
   - Functional dealer inventory: seven per page.
   - Demo dealership inventory: seven per page.
   - Driver directory: seven per page.

6. Dealership demo and internal routes
   - Rebuilt /dealership/truckstore-centurion-demo as a functional,
     Instagram-style test dealership profile.
   - Test account email: loadlinksouthafrica@gmail.com.
   - Follow state, inventory/update/about tabs, vehicle details and pagination
     work inside the demo.
   - “View all available trucks” stays inside LoadLink at /trucks.
   - The owner test email can open the functional dealership centre.
   - Dealer dashboard buttons now open real internal dealership tools.

7. Account creation
   - Added the missing /signup page so the existing Create Account link no
     longer leads to a missing route.
   - Supports Google OAuth and email/password registration.

DATABASE SUPPORT
- Added LOADLINK-PHASE-2-FINAL.sql.
- Adds profile-setting columns and safe profile update RPC.
- Adds driver profiles, private critical-document storage and review RPCs.
- Adds chat blocking and voice-note attachment support.
- Does not delete existing users, listings or conversations.
